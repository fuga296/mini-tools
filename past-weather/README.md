# 天気既報(例年の今日の気温)

指定した日(既定は今日)について、過去の各年のその日の気温を地点ごとに並べ、期間平均や「晴れた日だけの平均」を出すページ。

## 使い方
1. `index.html` をスマホかPCのブラウザで開く(インストール・ログイン不要)。
2. 日付(月日だけ使う)、地点(主要11都市 / 現在地 / 緯度・経度入力)、開始年〜終了年(既定は直近30年、1940年〜昨年)を選び「表示」。
3. 天気のチップ(晴れ・くもり・雨・雪・雷雨)で絞り込むと、該当した年だけで最高・日平均・最低の平均を出し直す。グラフと一覧の対象外の年は薄く表示。
4. 通信できないときは「見本」で画面だけ試せる(作り物の数値で、画面に明示される)。URL に `?demo` を付けると開いた時点で見本表示。

## 仕様
- データ: [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api)(`archive-api.open-meteo.com/v1/archive`)の daily `temperature_2m_max / min / mean`, `weather_code`, `precipitation_sum`。ブラウザから直接呼ぶ。外部通信はこの API だけ(フォントや他ライブラリも読み込まない)。
- 1年につき1日分の要求を1回(同時4件まで)。連続期間を1回で取るより呼び出し量の換算が小さいため。取得済みの値は localStorage に保存し、次回は通信しない。
- 2月29日は平年だと2月28日で代用(一覧に `*`)。
- 天気分類は WMO 天気コード: 晴れ 0–1 / くもり 2–3・霧 45,48 / 雨 51–67,80–82 / 雪 71–77,85–86 / 雷雨 95–99。daily の weather_code は「その日で最も悪い天気」なので、「晴れ」は一日中ほぼ晴れていた日に限られる。
- 値は再解析データ(格子点の推定値)で、気象台の観測値とは少しずれる。

## 利用条件とクレジット
- Open-Meteo の API は **非商用利用なら無料・API キー不要**。目安の上限は 1日 10,000 回 / 1時間 5,000 回 / 1分 600 回。商用利用は有料プランが必要。<https://open-meteo.com/en/terms>
- データは **CC BY 4.0**。表示には出典の明記が必要なため、ページ下部に「Weather data by Open-Meteo.com」とライセンスへのリンクを置いている。
- 元データ: ECMWF / Copernicus Climate Change Service の ERA5 などの再解析データ(Open-Meteo が提供)。
