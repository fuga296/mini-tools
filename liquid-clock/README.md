# liquid clock

画面の下から上へ液体が満ちていき、満ちたら空に戻る、波打つ液面の時計。

## 使い方
1. `index.html` をスマホ(縦画面推奨)のブラウザで開く。
2. 下のパネルで周期(1分 / 1時間 / 12時間)と液体の色を選ぶ。「設定を隠す」で全画面に近い表示になる。
3. 画面上部に現在時刻(時:分:秒)を小さく表示。

## 仕様
- 満ち具合は毎フレーム現在のローカル時刻から計算(1分=秒、1時間=分秒、12時間=0時/12時起点)。閉じて開き直しても実時間と一致する。
- 周期と色の選択だけ localStorage に保存(失敗しても動作する)。外部ライブラリ・通信なし。
