# fuckalendar

シードとレベルから作る、嘘のカレンダー。レベルが上がるほど嘘が増える。

## 使い方
1. `index.html` をブラウザで開く(スマホ可)。
2. 最初の画面でレベル(1〜5)を選び、「はじめる」を押す。シードを決めたいときは、小さな「シードを指定する」から入力する(空欄ならランダム)。
3. ‹ › で月を移動、「1年ぶん表示」で全部の月を一覧(月をタップするとその月へ)。
4. 上の「共有」で `index.html?seed=xxxx&lv=3&m=2` を共有すると、相手にも同じカレンダーが出る。「最初へ」で最初の画面に戻る。

## レベル
| Lv | 名前 | 内容 |
|---|---|---|
| 1 | ずれ | 普通の12か月カレンダー(実在の年・実在の日数)だが、曜日と日付がずれている |
| 2 | 水増し | 月の日数が26〜35日、曜日の並びが入れ替わる、架空の祝日 |
| 3 | 異世界 | 月の数が7〜19、謎の月名、曜日の漢字が別の字、架空の年号 |
| 4 | 崩壊 | 1週間が5〜10日、日付が飛ぶ・重複する、0日やマイナスの日、欠番マス、ときどき3〜45日の月 |
| 5 | 混沌 | 漢数字・ローマ数字・全角・小数・二進数が混ざる、逆向きに進む月、月ごとに曜日の並びが違う、マスの入れ替え、「今日」が複数(またはゼロ) |

上のレベルは下のレベルの嘘をすべて含む(Lv1 の「年」以外)。

## 嘘の方法の一覧
1. 曜日をずらす(1日目の曜日がずれている) — Lv1〜
2. 日付をずらす(月の途中の数字から始まり、末尾で1に戻る) — Lv1〜
3. 月の日数を変える — Lv2〜
4. 曜日の並び順を入れ替える — Lv2〜
5. 架空の祝日を入れる — Lv2〜
6. 月の数を変える — Lv3〜
7. 謎の月名(0月・13月・裏3月・π月など) — Lv3〜
8. 曜日の漢字を変える(泥・鍋・雲…) — Lv3〜
9. 架空の年号にする — Lv3〜
10. 1週間の日数を変える — Lv4〜
11. 日付が飛ぶ・重複する — Lv4〜
12. 0日やマイナスの日から始まる — Lv4〜
13. 欠番マスを入れる — Lv4〜
14. 数字の表記を混ぜる(漢数字・ローマ数字・全角・小数・二進数・「約」) — Lv5
15. 逆向きに進む月 — Lv5
16. 月ごとに曜日の並びが違う — Lv5
17. 隣のマスと入れ替える — Lv5
18. 「今日」がいくつもある(または存在しない) — Lv5

## 仕様
- 乱数は xmur3 + mulberry32。`シード|L(レベル)` から各レベルのカレンダーを作る。年(1990〜2040年)はシードだけで決まり、全レベル共通。
- 同じシードとレベルなら、いつ・どこで開いても同じカレンダー(実際の今日の日付は使わない)。
- 確率や範囲は `index.html` 冒頭の `CONFIG` で変えられる。
- 外部通信・保存・ログインなし。
