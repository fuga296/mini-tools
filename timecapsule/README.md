# 正解はn年後

期限まで誰にも(作った本人にも)開けられない問題を作り、期限が来たら出題して答え合わせできるタイムカプセル。

## 何か
- 問題と答えを、公開ランダムビーコン [drand](https://drand.love) を使った時限暗号(tlock)で封をする。期限の時刻の署名はまだ誰も持っていないので、期限前は誰も復号できない。
- サーバー・ログイン・課金・AI なし。ブラウザだけで動く。通信は開封時に drand の署名を1回取得するだけ(CSP で drand のリレー4か所に限定)。
- 方式の比較と限界は [DESIGN.md](DESIGN.md)。

## 使い方
1. `index.html` をブラウザで開く(GitHub Pages などに置くと、リンクで共有できる)。ホームには、この端末で作った・開いたカプセルが並ぶ。
2. ホームの「つくる」で、表書き(任意・期限前も見える)、問題、答え、開けられる時期(1か月〜10年後、または日時指定・最長30年)を入れて「封をする」。
3. 「カレンダーに追加(.ics)」で期限の日時に通知を入れる。リンクか `TC1.` で始まる文字列を保管・共有する。
4. 期限が来たら、ホームの一覧から開くか、「みる」にリンク/文字列を貼って「開けて出題する」。正解すると紙吹雪。

## 注意
- リンク/文字列を失くすと開けない(この端末の一覧には暗号のまま残る)。
- 開封時はネット接続が必要。drand が止まると永久に開けない(10年超は画面で注意)。
