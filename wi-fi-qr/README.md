# Wi-Fi QR

SSID・パスワード・暗号化方式・ステルス有無から、スマホで読み取って接続できるWi-Fi用QRコードを作るツール。

## 使い方
1. `index.html` をブラウザで開く。
2. SSID、暗号化方式(WPA/WEP/なし)、パスワード、必要なら「ステルスSSID」を入力。
3. 表示されたQRをスマホのカメラで読み取る。「印刷」ボタンで大きく印刷できる。

## 仕様
- 形式: `WIFI:T:...;S:...;P:...;H:true;;`。`; , : \ "` はバックスラッシュでエスケープ。
- 16進数文字だけのSSID/パスワードは、仕様どおり `"..."` で囲む。
- QR生成は自前実装(バイトモード・誤り訂正M・バージョン1〜14、最大約360バイト)。外部ライブラリ・通信・保存なし。
- 検証: OpenCV のデコーダで、特殊文字・日本語・絵文字・最大長の入力を、入力どおりの文字列として読めることを確認。
