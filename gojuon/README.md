# 五十音のいろは

五十音表を好きな構成・デザインで表示・印刷し、塗りつぶし・数え・ランダム表示・札あそびに使えるひらがな/カタカナの道具箱。

## 使い方
1. `index.html` をブラウザ(スマホ可)で開く。`kana.js` を同じフォルダに置いておく。
2. 上のタブで切り替える。
   - **表**: 五十音表を見る。「ひらがな ⇄ カタカナ」「印刷」。
   - **塗る**: マスを押すと黒く塗りつぶし、もう一度押すと戻る。「全部もどす」「全部塗る」。
   - **数える**: マスを押すたびに +1(「−1 する」に切り替えると減る)。多いマスほど濃い色。「全部 0 にする」。
   - **ランダム**: 表の全体から、または表で選んだ文字から n 個表示。重複なし/ありを選べる。
   - **札あそび**: ひらがなの札を並べてことばを作るひとり遊び(ルール案は `DESIGN.md`)。
   - **設定**: 表の構成とデザインを変える。下に見本が出る。
3. 塗り・数・設定・ゲームの途中経過はブラウザ内(localStorage)に保存される。「保存データを全部消す」で消せる。

## 設定できること
| 項目 | 選択肢 | 既定 |
|---|---|---|
| 「ん」 | わ行の次の列の上・中・下 / 表の外 / 入れない | 列の上 |
| ゐ・ゑ など | なし / 一部(ゐ・ゑ) / 全部(+や行え 𛀁・わ行う 𛄟) | なし |
| や行・わ行の空き | 空欄 / い・う・え を薄く | 空欄 |
| 濁音・半濁音・「ゔ」・小書き文字・拗音 | 入れない / 本表に続けて / 別の表 | 入れない |
| 文字・並び | ひらがな/カタカナ、縦(右から)/縦(左から)/横(行ごと) | ひらがな・縦(右から) |
| 書体 | ゴシック/明朝/丸ゴシック/教科書体/名前を入力、太字 | ゴシック |
| 寸法 | マス(画面幅に合わせる/指定 20–140px)、文字(マスの 25–95%)、線 0–6px、間隔 0–16px、見出し | 自動(上限 56px)・62%・1px・0px・なし |
| 色 | 文字・マス・線・台紙・塗り・数 | 白地に黒 |

- 拗音の ぎゃ・じゃ・びゃ / ぴゃ は、濁音 / 半濁音を入れたときだけ加わる。ぢゃ 行は入れていない。
- 書体は端末に入っているものだけを使う(Web フォントの読み込みはしない)。や行え・わ行う は対応書体がないと □ になる。
- 印刷すると、今のタブの表だけが A4 縦の幅に合わせて出る(塗り・数も印刷される)。

## ライブラリ `kana.js`
画面に依存しない文字データと処理。ブラウザでは `window.Gojuon`、Node では `require('./kana.js')`。

```js
const G = require('./kana.js');
const t = G.build({ n: 'col-top', archaic: 'some', dakuon: 'separate' }); // 表を組み立てる
G.cellsOf(t).map(c => c.h);   // 表の全文字(表→行→段の順)
G.toKatakana('きゃっと');      // 'キャット'
G.splitUnits('しゃしん');      // ['しゃ','し','ん']
G.sample(['あ','い','う'], 5, { unique: false });
G.variants('は');              // ['は','ば','ぱ'] 濁点・半濁点・小書きの読みかえ
G.makeDeck(2, 1);              // 札あそびの山札
```

外部ライブラリ・通信・サーバー・ログインなし。
