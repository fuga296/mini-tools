# 五十音のいろは

五十音表を好きな構成・デザインで表示・印刷し、塗りつぶし・数え・ランダム表示・札あそびに使えるひらがな/カタカナの道具箱。

## 使い方
1. `index.html` をブラウザ(スマホ可)で開く。`kana.js` と `fonts/` を同じフォルダに置いておく。
2. ヘッダーのドロップダウンでページを選ぶ。ⓘ でそのページの説明が出る。
   - **五十音表**: 表を大きく表示。「あ/ア」で表記切替、印刷ボタンで表だけを印刷。
   - **チェック表**: 押すと反応する表。ドロップダウンで「黒塗り」(押すと塗りつぶし・もう一度で戻す、全部塗る/全部消す)と「カウント」(押すたび +1、「押すと −1」で減らす、リセット)を切り替える。
   - **あそび**: ドロップダウンで「文字くじ」(表の全体か、表で選んだ字から n 個。重複なし/あり)と「ことば札」(札でことばを作る。ルール案は `DESIGN.md`)を切り替える。
   - **設定**: 表が上に固定されたまま、下のドロップダウンで構成・見た目・ことば札の枚数を変える。
3. 構成: 「ん」の位置(わ行の次の上・中・下/表の外/なし)、ゐ・ゑ(なし・一部・全部=+や行え・わ行う)、空きマス(空欄・い/う/えを薄く)、濁音・半濁音・ゔ・小書き・拗音(入れない・本表に続けて・別の表)。
4. 見た目: ひらがな/カタカナ、並び(自動・縦右から・縦左から・横)、書体、太さ、見出し、マスの大きさ(画面に合わせる/固定)、字の大きさ、線、間隔、配色(5 種)と個別の色。
5. 設定・黒塗り・カウント・くじ・ことば札の途中経過はブラウザ内(localStorage)に保存される。

## 決めた既定値
| 項目 | 既定 | 理由 / 代わりの案 |
|---|---|---|
| 構成 | 清音 46 字、ん は わ行の次の列の上、ゐゑ なし | 一般的な五十音表 |
| 並び | 自動(縦長スマホは横、他は縦・右から) | スマホ縦で縦書き表だと 1 マス約 30px にしかならず、横なら約 44px。固定したい人は調整で選ぶ |
| マス | 画面の幅と高さに収まる最大(上限 96px) | 表を主役にするため。「固定」で印刷用などに一定の大きさにできる |
| 字の大きさ / 線 / 間隔 | マスの 64% / 1px / 0 | 罫線の表として読みやすい比率。間隔を空けるとカード風になる |
| 書体 | 教科書体風(Klee One) | 手書きに近い字形でかなの形がわかりやすい。明朝(Zen Old Mincho)も同梱。ほかは端末の書体 |
| 角の丸み | 3px | 和紙・札の印象に寄せて控えめに |

- 拗音の ぎゃ・じゃ・びゃ / ぴゃ は、濁音 / 半濁音を入れたときだけ加わる。ぢゃ 行は入れていない。
- 同梱フォントは表と画面で使う字だけに絞ったサブセット(SIL Open Font License、`fonts/OFL-*.txt`)。外部から読み込まない。

## ライブラリ `kana.js`
画面に依存しない文字データと処理。ブラウザでは `window.Gojuon`、Node では `require('./kana.js')`。

```js
const G = require('./kana.js');
const t = G.build({ n: 'col-top', archaic: 'some', dakuon: 'separate' }); // 表を組み立てる
G.cellsOf(t).map(c => c.h);   // 表の全文字(表→行→段の順)
G.toKatakana('きゃっと');      // 'キャット'
G.splitUnits('しゃしん');      // ['しゃ','し','ん']
G.sample(['あ','い','う'], 5, { unique: false });
G.variants('は');              // ['は','ば','ぱ'] 濁点・半濁点・小書きの読みかえ
G.makeDeck(2, 1);              // 札あそびの山札
```

外部ライブラリ・通信・サーバー・ログインなし。
