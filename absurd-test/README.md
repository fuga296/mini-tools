# 究極の性格診断

いろいろな診断の設問をごちゃまぜに出して、もっともらしい文体で中身がめちゃくちゃな結果を返す性格診断。

## 使い方
1. `index.html` をブラウザで開く(スマホ可)。
2. 「はじめる」→ 全12問に答える → 結果が出る。
3. 決まったシードで始めたいときは、小さな「シードで始める」から入力する。
4. 結果画面の一番下「この診断について」に、元ネタのジャンル・シード・共有URL(`index.html?seed=xxxx`)がまとまっている。URLを開くと同じ質問・同じ結果になる。

## 仕様
- 設問と結果の文はすべて `data.js` に同梱した自作の文(設問182問・13ジャンル、解説文81、タイプ名2116通りなど)。実行時に AI や通信は使わない。
- シードから乱数(xmur3 + mulberry32)を作り、設問の選び方・選択肢の型・結果をすべて決める。「はじめる」では毎回ランダムなシードが付く。
- **結果はシードだけで決まり、回答内容は使わない。** 同じシードなら、どう答えても同じ結果。
- 結果にはレーダーチャートと棒グラフ(性格バランス)が出る。値はシードで決まり、左右の合計が100にならなくてもよい。
- 質問中・結果本文にはシードも出典も出さない。元ネタは結果画面の最下部(折りたたみ)のみ。
- 1ジャンルから最大3問までに抑え、複数ジャンルが混ざるようにしている。
- 設問数・分析中の秒数・各項目の数などは `index.html` 冒頭の `CONFIG` で変えられる。
- 外部通信・保存・ログインなし。
