# 究極の性格診断

いろいろな診断の設問をごちゃまぜに出して、もっともらしい文体で中身がめちゃくちゃな結果を返す性格診断。

## 使い方
1. `index.html` をブラウザで開く(スマホ可)。
2. 「はじめる」→ 全12問に答える → 結果が出る。
3. 決まったシードで始めたいときは、小さな「シードで始める」から入力する。
4. 結果画面の一番上の「URLをコピー」「共有」で、同じ質問・同じ回答の結果を送れる(`index.html?seed=xxxx&a=...`)。

## 画面(3つのみ)
- ホーム:サイト名・説明文・「診断を始める」だけ。1画面に収まり、スクロールしない。「シードで始める」は小さな文字リンクで下に置いている。
- 診断:質問文・選択肢・「次へ」(最後は「診断する」)。1画面に収まる。選択してから「次へ」で進み、「← 戻る」で前の質問に戻れる。
- 結果:「診断結果」の見出しのもと、タイプ名・キャッチコピー・共有ボタンを上に置き、総合所見・主な傾向・長所と短所・対人関係・適性・特記事項の順に並べる。最後に「もう一度診断する」「ホームに戻る」。
- 配色は白・墨色・濃紺(#34465A)、見出しと結果タイトルは明朝体(Noto Serif JP)、本文はゴシック(Noto Sans JP)。角丸8px・影なし・アニメーション最小。

## 仕様
- 設問・結果の文はすべて `data.js` に同梱した自作の文(設問288問・18ジャンル、解説文110超、タイプ名2116通りなど)。実行時に AI や通信は使わない。
- **シードで決まるのは質問の組み合わせ。結果はシード+回答の組み合わせで決まる**(回答が1つ違えば別の結果。同じシードで同じ回答なら同じ結果)。
- 選択肢は「はい/いいえ」「あてはまる〜あてはまらない」などの普通の形。
- スコアは必ず具体的な数値(%・点・偏差値など)で出る。
- 結果にはレーダーチャートと棒グラフ(性格バランス)、長所短所、人間関係、職業・趣味、10年後、ラッキーなど。
- 質問中と結果本文にはシードも出典も出さない。元ネタジャンルとシードは結果最下部(折りたたみ)のみ。
- 「「◯◯」タイプ」は改行せず、長いときは文字を縮小して1行に収める。
- 設問数・各項目の数などは `index.html` 冒頭の `CONFIG` で変えられる。
- 外部通信・保存・ログインなし。
