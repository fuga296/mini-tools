# ありえない性格診断

いろいろな診断の質問をごちゃまぜに出して、もっともらしい文体で中身がめちゃくちゃな結果を返す性格診断。

## 使い方
1. `index.html` をブラウザで開く(スマホ可)。
2. シード欄はそのままでも、好きな文字列に変えても、🎲で作り直してもよい。
3. 「診断をはじめる」→ 全12問に答える → 結果が出る。
4. 結果画面の「URLをコピー」で `index.html?seed=xxxx` を共有すると、相手も同じ質問・同じ結果になる。

## 仕様
- 設問と結果の文はすべて `data.js` に同梱した自作の文(設問182問・13ジャンル、解説文81、タイプ名2116通りなど)。実行時に AI や通信は使わない。
- シードから乱数(xmur3 + mulberry32)を作り、設問の選び方・選択肢の型・結果をすべて決める。
- **結果はシードだけで決まり、回答内容は使わない。** 同じシードなら、どう答えても同じ結果。
- 1ジャンルから最大3問までに抑え、毎回5種類以上の診断が混ざるようにしている。
- 長所と短所に同じ特徴が必ず1つ入り、相性の良いタイプと悪いタイプが同じになることもある(わざと)。
- 数値は `index.html` 冒頭の `CONFIG`(設問数・分析中の秒数・各項目の数など)で変えられる。
- 外部通信・保存・ログインなし。
